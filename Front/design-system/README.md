세부 px/pt·그림자·opacity 수치는 승인 시안을 일관되게 재현하기 위한 정규화된 설계값이다. 생성 이미지의 모든 픽셀이 실제 폰트/레이아웃 측정값인 것은 아니다. 구체적인 사용자 지시와 DESIGN.md/토큰을 함께 적용한다. 지도·위치·3D 기능 계약은 기존 구현을 유지한다.

그림은 built-in image_gen으로 만든 시안 원본을 변경 없이 복사했다. 후속 코드 적용 요청으로 React/CSS에 반영했다. 서버와 PR은 이번 로컬 수정 범위에서 변경하지 않았다.
