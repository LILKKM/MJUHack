## Brand

`Seoul Times`. 한지 크림, 검은 Chomsky 제호, 남색 텍스트, 민트 행동 강조. 장소·기사를 읽는 데 집중한다. 과장된 굵기·큰 닫기 상자·빽빽한 선·메타데이터 나열을 줄인다. 지도/홍길동은 기존 실제 기능·모델을 유지한다.

## Product goals

목록은 장소 이름을 빠르게 찾고, 검색은 필요할 때 펼친다. 핀 선택은 가벼운 장소 카드로, 주변 추천은 짧은 정사각형 대화창으로 이어진다. 여백·정렬·그림자로 지도/탐색/주요 창의 위계를 표현한다. 위치 판정·신문 게시 상태·서버 연결은 디자인 승인과 구분한다.

## Personas and jobs

관광객·내국인이 휴대폰 지도에서 장소를 고르고 현장 신문을 읽는다. 키보드 이용자에게도 장소 목록/검색/대화 입력/닫기와 명확한 초점을 제공한다.

## Information architecture

지도 상단 제호와 하단 한 행 두 버튼을 공통 구조로 사용한다. `장소 목록`과 `주변 추천받기`는 아이콘 없는 글자 버튼이다. 기본 탐색 버튼은 크림 면·남색 글자/외곽선, 카드 안의 주 행동은 민트다. 지도 자체의 제공자 표시는 별도 유지한다.

목록을 열면 `장소` 제목, 반대편 작은 검색 아이콘, 얇은 제목 구분선과 장소 이름만 보인다. 검색 아이콘을 누르면 제목 아래에 지역·시대·장소 검색이 펼쳐지고 다시 누르면 접힌다. 장소명 옆에 ID/좌표 상태/카운트를 붙이지 않는다. 닫힌 검색의 필터 적용 상태는 접근 가능한 이름/상태로 알리되 거짓 전체 결과를 표시하지 않는다.

반경 밖 핀은 중앙 정렬의 장소 카드와 짧은 토스트, 방문 가능한 신문은 기존 하단2/3 지면을 사용한다. 추천 창은 정사각형 패널이다. 목록·추천 창과 선택 카드가 동시에 겹쳐 지도를 덮지 않게 한다.

## Design principles

- 같은 내용축과 충분한 안쪽 여백을 사용한다. 텍스트를 카드 왼쪽 모서리에 붙이지 않는다.
- 토스트/장소 카드의 내용은 중앙 정렬, 목록/대화는 안쪽으로 이동한 동일 시작점에서 왼쪽 정렬한다. 목록창 외곽은 기존 크기를 유지한다.
- 한글은 자연스러운 표준 장평이다. scaleX·강제 압축이나 합성 굵기를 쓰지 않는다.
- 테두리는 얇고 짧게, 주요 위계는 부드러운 남색 그림자로 표현한다.
- 색·문구·상태를 함께 사용하고 원본 데이터/신문/3D·위치 계약을 보존한다.

잠긴 선택 카드는 장소명과 사용자가 제공한 소개 한 문장만 표시한다. 시대·주소·추가 아이콘·20m 안내·현재 위치 확인 버튼은 카드에서 제거한다. 기존 토스트와 방문 판정은 유지한다. 소개는 한국어 편집 검토본으로 역사 검증 완료나 방문 인증을 뜻하지 않는다. 목록의 원본 이름에 포함된 문장부호는 장소 데이터이며 삭제 대상인 ID·중간점·좌표 상태 메타행과 구분한다.

## Accessibility

WCAG2.2 AA 목표. 작은 X/검색 글리프에도44px 입력 영역, 검색 버튼의 접근 가능한 이름과 aria-expanded/controls를 제공한다. 검색을 펼치면 입력으로, 접으면 검색 버튼으로 초점을 자연스럽게 복원한다. 모달 Tab 순환과 Escape 닫기, 닫기 후 진입 버튼으로 초점 복귀를 유지한다.

스크롤바를 숨겨도 휠·터치·방향키/PageDown을 사용할 수 있어야 한다. 긴 장소명은 줄바꿈하고 잘라서 정체를 잃지 않게 한다. 확대/큰 글씨에서는 정사각 비율보다 내용/입력 접근을 우선해 내부 스크롤·safe area를 보장한다. 토스트 배경 투명도와 실제 지도 위 대비는 구현 시 별도 검증한다. 메타 역할을 행동 안내나 긴 본문으로 사용하지 않는다. 목록행의 컴팩트 여백 요청은24px 하한을 적용하고 검색/닫기/하단/복귀 버튼은44px 이상 유지한다.

## Responsive behavior

5:12 앱 프레임을 유지한다. 목록과 추천 창은 같은 폭 토큰과1:1 기본 비율을 사용한다. 제목/검색은 고정 헤더, 내용은 스크롤, 추천 입력창은 고정 하단이다. 가상 키보드/200% 확대/낮은 화면에서는 입력과 닫기가 가려지지 않도록 사용 가능 높이를 우선한다. 하단 두 버튼의 크기·간격은 글씨5% 축소와 별개로 유지한다.

## Interaction states

첫 구름 화면 하단에 `아래로 스크롤`과 아래 화살표를 표시하고 진입 시작 시 숨긴다. reduced-motion에서는 화살표가 정지한다. 민트 원형 복귀 버튼은 최신 홍길동 위치로 지도만 이동한다. 지도 아바타 yaw는0으로 표시한다.

기본 목록: 제목/검색 아이콘/이름 행. 검색 펼침: 지역·시대·장소 검색과 결과. 0건: 짧은 빈 결과/조건 초기화 행동. ID/좌표 상태·집계줄·스크롤바는 기본 목록에 노출하지 않는다. GPS/좌표 없는 장소의 오류는 실제 선택 시 사실대로 안내한다.

토스트는180ms ease-in→2400ms 표시→220ms ease-out, 연타는 한 메시지 갱신. reduced-motion은80ms 불투명도만 사용한다. 챗봇의 전송 중/연결 실패/입력 보존/재시도, 신문 파일/TTS 실패 상태는 기존 계약을 유지한다. 숨겨진 메타정보를 방문 인증 성공으로 바꾸지 않는다.

## Content voice

짧고 정중한 한국어/영어. 장소 제목은 `장소`, 하단 라벨은 `장소 목록`/`주변 추천받기`다. 추천 제목은 `주변 추천`. 잠긴 카드 본문은 사용자가 제공한 한국어 소개 문장만 표시한다. 사용자에게 중복 상태 문장이나 내부 sourceId를 나열하지 않는다. 개발/검토 상태를 숨겨 실제 방문/게시 승인을 가장하지 않는다.

## Implementation constraints

사용자가 코드 적용을 승인해 Front/src/의 기존 컴포넌트와 토큰을 갱신한다. 백엔드·공통 계약·좌표·신문 원본·연출 타이밍을 변경하지 않는다. PR #6은 추가 푸시 전 상태다. 목록창과 글씨 크기를 유지하며 5.5개가 보이도록 행 여백을 조절했다.

Plan/Design: 승인 시안과 최신 지시를 대조했다. Build: 기존 React/CSS에 적용했다. Test: 24 suites/75 tests, production build PASS. 실제 브라우저320/390px에서 여섯째 행 노출 비율0.50과 첫 화면 스크롤 안내/시작 시 숨김을 확인했다. 지정된 how/architect/cross-validation-skill 등은 현재 카탈로그에 없어 직접 코드 확인·테스트·브라우저 검증으로 대체했다. Deploy/PR/push는 이번 로컬 변경에서 N/A.
