# Design

## Source of truth

Active · 2026-11-06 Asia/Seoul. [루트 디자인](../../../../DESIGN.md)의 팔레트·느좋체/Abhaya·홀수 정수 pt를 적용한다. 이후 사용자가 직접 바꾼 **Seoul Times 대문자 S/T, NYT 스타일 블랙레터 제호, 검은 제호 글씨, 스크롤 진입, 반경 밖 떠 있는 카드**는 해당 항목의 최신 기준이다. 베이지/남색 제호·소문자·BEGIN 관찰 화면에 관한 과거 인계보다 이 문서를 우선한다.

근거: [브랜드 CSS](src/styles/brand.css), [방문/신문 계약](../../../../integration/NEWSPAPER_VISIT_TTS.md), [신문 연결 인계](../../../../handoff/frontend/NEWSPAPER_VISIT_TTS.md), [폰트 출처/고지](public/assets/fonts/README.md).

## Brand

DOM 제호는 `Seoul Times`. Chomsky 블랙레터를 검은색으로 사용한다. 실제 NYT 로고 파일을 쓰지 않으며 고유한 서비스명을 유지한다. 본문은 느좋체와 Abhaya Libre ExtraBold다. 검토 전 기사와 개발 시뮬레이션을 실제 방문 인증·게시 승인으로 표시하지 않는다.

## Product goals

스크롤 → 홍길동의 1초 응시 → 먼저 뛰어내림 → 뒤따르는 구름 하강 → 같은 네이버 지도에 착지 → 현장20m 신문으로 이어진다. 핀을 눌렀다는 이유로 전체 장소 목록이 자동으로 올라오지 않는다.

## Personas and jobs

관광객·내국인이 현장에서 휴대폰으로 역사 장소를 탐색하고 기사를 읽거나 듣는다. 지도와 동등한58곳 목록, 키보드 선택, 읽을 수 있는 동등 본문을 제공한다.

## Information architecture

처음은 구름만 보인다. 아래 스크롤·위로 쓸기·키보드 아래 방향키/PageDown/Space로 시작한다. BEGIN·내려가기·지도 둘러보기 CTA는 없다. 지도 상단은 중앙 한지 제호이며 좌우 불필요한 지도 버튼은 없다. 아래의 아이콘 없는 라운드 두 버튼에서 목록/주변 추천을 열고, 위치 설정과 개발 도구는 그 안에 둔다.

반경 밖 선택은 지도 위에 사방 여백을 둔 작은 카드와 접근 안내 토스트다. 20m 안에서 명시적으로 선택하면 하단2/3 신문을 연다. 뒤의 지도는 셰이드로 남긴다. 음성·언어 컨트롤은 신문 내부, 챗봇 버튼은 지면 아래에 둔다. 주변 추천 버튼은 실제 Spring API 대화창을 연다. 연결 실패는 입력을 유지하며 안내한다.

## Design principles

- 크림 한지 면과 검은 블랙레터 제호를 상단 기준으로 사용한다.
- UI 색·글자 크기는 역할 토큰을 사용하고 사용자 최신 예외만 명시한다.
- 원본116개 신문 SVG는 재조판하거나 장평을 변형하지 않는다.
- 지도 입력·GPS 원본·핀 좌표는 장식 때문에 바꾸지 않는다.

한글과 라틴은 @font-face unicode-range로 분리한다. 느좋체의 원래 장체 위에 scaleX·강제 압축을 추가하지 않는다. 서체는 로컬에서 제공하며 SIL OFL 전문과 출처를 배포한다. 지도 타일·3D·삽화의 원래 색과 사용자가 요구한 범위 밖 회색 음영은 UI 팔레트와 별개다. 그림자와 사용자 UI 셰이드는 남색 투명도에서 파생한다.

## Components

`brand.css`가 제호/한지/색/pt 토큰, `WorldControls`가 수동 목록과 설정, `VisitOverlays`가 떠 있는 카드/토스트, `NewspaperSheet`가 지면·셰이드·언어·음성을 소유한다. `hongGilDongGLB.js`가 v3 GLB의 비행/응시/착지/탑뷰 포즈 경계다. 기존 절차형 모델은 복구용으로 보존한다.

## Accessibility

목표는 WCAG2.2 AA다. 제호는 읽을 수 있는 DOM 텍스트다. 버튼 입력 영역은44px 이상, 남색2px focus/2px offset, 지도 핀은 장소 이름과 Enter/Space를 지원한다. 목록 손잡이의 aria-expanded와 방향키·스와이프를 보존한다. 신문은 모달 초점과 Tab 순환·Escape 닫기를 제공하며 Escape가 뒤의 모션까지 토글하지 않는다. SVG 실패 시에도 기사 전체를 읽는다. TTS는 명시 클릭이며 자동 재생하지 않는다.

## Responsive behavior

앱은 width=min(100vw,100svh×5/12), height=min(100svh,240vw)로5:12를 유지한다. container query로 제호 크기를 프레임 폭에 맞춘다. 중앙 프레임 오프셋은 Three GPS 앵커에서 차감한다. 신문 높이는 프레임의66.666667%, 내부를 스크롤한다. 떠 있는 카드는 좌우12px·아래112px 여백과 최대 높이를 가지며 지도 위에 고정된다.

## Interaction states

위치 미확보/거부/낮은 정확도/30초 초과 관측/장소 좌표 없음/20m 밖/파일 실패/음성 미지원·없음·오류를 구분한다. 30초는 클라이언트 UX의 신선도 기본값이며 서버 계약이 아니다. 신문이 열린 뒤 위치가 유효하지 않거나 반경 밖으로 갱신되면 닫고 낭독을 취소한다. 반경 안으로 이동만 해서는 신문을 자동으로 열지 않는다.

토스트는180ms ease-in 진입,2400ms 유지,220ms ease-out 퇴장이다. 연타는 한 메시지를 갱신한다. reduced-motion은80ms 불투명도만 사용한다. 홍길동의1초 응시는 유지하고 낙하 전환은 생략한다. Escape·백그라운드 비활성은 연출 시간을 멈춘다.

## Content voice

짧고 정중한 한국어/영어다. navigator.language가ko/ko-*면 한국어, 나머지는 영어이며 기본 언어가 없을 때만 languages[0]을 사용한다. 제호 아래 가상 위치 개발 시연 문구는 제거했다. 개발 방문 시뮬레이션은 설정·신문/카드 안에서 명시하며 실제 GPS로 혼용하지 않는다.

## Implementation constraints

React JavaScript·react-scripts·기존 CSS/Three를 유지하고 새 의존성을 추가하지 않는다. 원본 기사·SVG·review/publication 상태를 보존하고58 sourceId를 정확히 연결한다. 선택한 한 언어 파일만 열람 시 지연 로딩한다. 현재 서버 방문 인증/게시 필터/챗봇의 실제 서버 응답은 미검증이며 백엔드/DDL/공통 계약은 수정하지 않는다. 로컬 UX 게이트는 정적 파일 URL 접근 제어가 아니다.
