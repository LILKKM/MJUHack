# 조선100년체 출처

조선100년체 지적재산권자: 방일영문화재단.
공식 배포·사용 조건: https://event.chosun.com/100/100font.html
사용자가 지정한 WOFF2 배포본: https://gcore.jsdelivr.net/gh/projectnoonnu/noonfonts_2206-02@1.0/ChosunCentennial.woff2

폰트 바이트를 수정하지 않고 사용했다. 공식 안내는 개인·기업 무료 사용과 자유로운 배포를 허용하며, 배포 대가 청구 및 수정 판매를 제한한다. 자세한 조건은 공식 안내를 따른다. Abhaya Libre와 Noto Serif KR의 별도 OFL 고지도 같은 폴더에 포함했다.
