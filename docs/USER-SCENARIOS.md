# 유저 시나리오 v0.1

서북권 역사 배리어프리 여행 서비스 · 2026-11-06 기준 데이터(장소 42곳, 연결 7개, 기사 42건)

프론트 화면과 시연을 만들 때 기준으로 쓴다. 코스와 응답 예시는 실제 서버 결과에서 가져왔다. API 형식은 [API-SPEC.md](API-SPEC.md) 참고.

## 검증 상태

| 표시 | 뜻 |
| --- | --- |
| ✅ 실제 | 실행 중인 서버에서 응답 확인 (AI 시나리오는 실제 Claude 호출) |
| 🧪 테스트 | 자동 테스트로 확인 (AI 응답은 가짜) |
| 🖥 화면 없음 | 프론트가 아직 없다. 모든 시나리오는 API 까지만 확인했다 |

## 이용자

| 이용자 | 이동 조건 | 서버가 확인하는 항목 |
| --- | --- | --- |
| 휠체어 이용자 | 계단·급경사 불가 | 필수: 접근로. 선호: 출입구, 엘리베이터, 장애인 화장실, 주차 |
| 고령자·보행 약자 | 긴 걸음 부담 | 선호: 접근로, 벤치·쉼터 |
| 유모차 동반 가족 | 유모차 동선 | 필수: 접근로. 선호: 출입구, 유모차, 수유실 |
| 시각장애인 | 점자·음성 안내 | 선호: 점자블록, 음성 안내, 보조견 |
| 청각장애인 | 자막·수어 | 선호: 자막·수어 안내 |
| K-콘텐츠 팬 | 제약 없음 | 없음 |

필수 항목이 '없음'으로 **확인된** 장소만 코스에서 뺀다. 확인되지 않은 곳은 빼지 않고 "미확인"으로 표시한다.

## S1. 자유 문장으로 코스 받기 (핵심 시연)

**이용자:** 휠체어를 타는 대학생. 영화 「1987」을 봤고 학교 근처 역사를 걸어보고 싶다.

1. 입력창에 쓴다: "휠체어 타요. 1987 봤어요. 명지대에서 출발해요."
2. Claude 가 조건을 파악한다: 휠체어, 작품 「1987」(현대), 출발 양호 거사비.
3. 서버가 현대 장소를 고른다. 밤섬은 "조망만 가능"이라 빠진다.
4. 코스 카드와 지도, 설명을 본다.

| 순서 | 장소 | 직선거리 | 접근성 |
| --- | --- | --- | --- |
| 1 | 강경대 민주광장(추모 동판) | 0.04km | 접근로 미확인 |
| 2 | 강경대 열사 거리·표지석 | 0.12km | 접근로 미확인 |
| 3 | 이한열 열사 피격 현장 동판 | 2.53km | 접근로 미확인 |
| 4 | 대한민국역사박물관 | 3.81km | 접근로 있음 ("출입구까지 단차가 없어 휠체어 접근 가능함") |

**반드시 보여야 할 것:** 장소별 미확인 항목, "장소 사이 이동 경로의 접근성은 확인되지 않았습니다", "거리는 직선거리", 시기 연결(명지대 캠퍼스, 연세대 캠퍼스).

**API:** `POST /api/courses/recommend` · **상태:** ✅ 실제

## S2. 대화로 코스 고치기

**이어서:** S1 의 이용자가 "두 번째 장소는 빼줘. 그리고 안산 봉수대를 넣어줘."라고 쓴다.

1. 두 번째 장소가 빠지고 새 코스 카드가 나온다.
2. 안산 봉수대는 서버가 막는다 (접근로 없음).
3. Claude 가 넣지 못한 이유를 설명하고, 서대문형무소역사관 같은 대안을 제시한다.

**확인 포인트:** 조건을 자동으로 완화하지 않는다. 코스 번호(`course.id`)가 새로 생긴다.

**API:** `POST /api/chat/sessions/{id}/messages` · **상태:** ✅ 실제

## S3. 가족 여행, 시간 맞추기

**이용자:** 유모차를 끌고 고령의 부모님과 함께 온 가족. 여유 시간 2시간, 경복궁역 출발, 조선 시대.

1. 조건을 입력한다 (복수 선택: 유모차 + 고령자).
2. 2시간이므로 3곳이 나온다: 경복궁 → 국립민속박물관(0.26km) → 북촌한옥마을(0.38km).
3. 산지인 안산 봉수대와 북한산성은 빠지고, 빠진 이유가 함께 보인다.
4. 경복궁은 접근로가 미확인으로 표시된다.

**API:** `POST /api/courses` · **상태:** ✅ 실제

## S4. 시각장애인 이용자, 작품에서 시작하기

**이용자:** 시각장애인. 「암살」을 봤고, 독립문 근처에서 출발한다.

1. 음성 안내로 "「암살」"을 고른다.
2. 서대문형무소역사관 → 임시정부기념관 → 서대문독립공원 → 독립관 코스가 나온다. 출발 장소는 항상 1번이다.
3. 장소별로 점자블록·음성 안내·보조견 정보가 메모로 나온다. 정보가 없으면 "미확인"으로 안내한다.
4. 화면 낭독기로 모든 내용을 읽을 수 있다. 기사 이미지에는 대체 텍스트가 있다.

**확인 포인트:** 이 시나리오를 돌려보다 메모가 비는 문제와, 출발지가 2번으로 밀리는 문제를 찾아 고쳤다. 네 곳 모두 점자 정보가 없어 Claude 가 "직접 물어보시길 권해요"라고 안내한다.

**API:** `POST /api/courses/recommend` · **상태:** ✅ 실제 (순서 수정은 🧪 테스트)

## S5. 그날의 기사 읽기

**이용자:** 코스의 첫 장소에 도착한 대학생.

1. 강경대 민주광장 카드를 누른다.
2. 재구성 기사를 읽는다: 「1991년 5월 15일 · 서울 — 고 강경대 군 영결식, 노제는 끝내 무산」.
3. 기사 위에 "실제 보도가 아닌 재구성 기사입니다" 안내가 보인다.
4. 숨은 이야기, 출처 링크, 같은 땅의 다른 시대(양호 거사비)로 이어간다.

대화로 물어도 된다: "첫 장소 기사 보여줘". Claude 가 재구성 기사임을 먼저 밝히고 보여준다.

**API:** `GET /api/spots/{id}` (`articles[]`), 챗봇 메시지 · **상태:** ✅ 실제 (대화), 🧪 테스트 (조회 API)

## S6. 주변 식당 묻기

**이용자:** 대한민국역사박물관을 본 휠체어 이용자. "근처에 휠체어로 갈 수 있는 식당 있어?"

1. 서버가 박물관 반경 1km 식당 5곳을 찾는다.
2. 접근성 근거가 없으므로 "휠체어로 갈 수 있다고 말씀드릴 수 없어요"라고 답하고, 직접 문의를 안내한다.

**확인 포인트:** 관광지가 접근 가능해도 식당까지 접근 가능하다고 말하지 않는다. 현재 식당 무장애 상세는 수집하지 않았다.

**API:** 챗봇 메시지 · **상태:** ✅ 실제

## S7. K-콘텐츠 팬, 촬영지인지 묻기

**이용자:** 이동 제약이 없는 해외 팬. 「킹덤」을 봤다. "여기 킹덤 촬영지야?"

1. 경복궁 출발 조선 코스: 경복궁 → 국립민속박물관 → 북촌한옥마을 → 창덕궁 → 창경궁.
2. 촬영지를 묻자, 같은 시대를 다룬 추천 태그일 뿐이며 촬영 여부는 자료로 확인되지 않는다고 답한다.
3. 영어로 물으면 영어로 답한다.

**API:** 코스, 촬영지 답변, 영어 답변 모두 ✅ 실제 (촬영지·영어 답변은 「1987」, 「암살」로 확인)

## S8. 정보가 부족할 때

**이용자:** "코스 짜줘"라고만 쓴다.

1. Claude 가 작품이나 시대, 출발지를 한 번에 묻는다. `course` 는 `null` 이다.
2. 답하면 앞서 말한 조건을 다시 묻지 않고 코스를 만든다.

**API:** `POST /api/courses/recommend` → 챗봇 메시지 · **상태:** ✅ 실제

## S9. 문제가 생겼을 때

| 상황 | 이용자가 보는 것 | 코드 | 상태 |
| --- | --- | --- | --- |
| API 키 없음 | AI 기능을 쓸 수 없다는 안내. 일반 코스·장소 조회는 정상 | `503 LLM_NOT_CONFIGURED` | ✅ 실제 |
| Claude 호출 실패 | 다시 시도 안내. 코스와 장소 정보는 그대로 | `502 LLM_UNAVAILABLE` | 🧪 테스트 |
| Claude 가 답변 거절 | 다시 물어봐 달라는 안내 | `200` 안내 문구 | 🧪 테스트 |
| 조건에 맞는 장소 없음 | 조건을 바꿔 보라는 안내. 자동으로 완화하지 않음 | `422 NO_CANDIDATES` | 미확인 |
| 세션 만료 (24시간) | 새로 시작 안내 | `410 SESSION_EXPIRED` | 미확인 |
| 없는 장소 ID 가 답변에 나옴 | 서버가 지운 뒤 보여줌 | - | 🧪 테스트 |

## 시연 추천 순서 (3분)

1. **S1** 자유 문장 한 줄로 코스가 나온다.
2. **S2** 안산 봉수대를 넣어 달라고 해서 서버가 막는 장면을 보여준다.
3. **S5** 기사를 읽고 같은 땅의 다른 시대로 넘어간다.
4. **S7** "촬영지야?" 질문으로 지어내지 않는 모습을 보여준다.

## 시나리오에서 드러난 한계

| 한계 | 예시 | 영향 |
| --- | --- | --- |
| 다음 장소까지 거리 상한이 없다 | 진관사 출발 개화기 코스의 세 번째 장소가 7.25km 떨어져 있음 | 이동 약자에게 비현실적인 코스가 나올 수 있음 |
| 시각·청각·고령자 유형에는 필수 조건이 없다 | 점자 정보가 없어도 추천됨 | 미확인 표시에 의존 |
| 명지대 지점 접근성이 전부 미확인이다 | S1 의 1~3번 | 핵심 시연 코스인데 경고가 많음. 현장 확인이 가장 효과적 |
| 16곳 삭제로 연결 이야기가 줄었다 | X7 은 양화진·망원정 2곳만 남았는데 설명은 절두산 중심. 단종 연결(X8)은 사라짐 | 「왕과 사는 남자」 추천 근거가 약해짐 |
| 기사에 인용문이 있다 | 42건 중 일부에 따옴표 인용 | 기획서의 "지어낸 인용문 금지" 원칙과 충돌할 수 있어 팀 확인 필요 |
